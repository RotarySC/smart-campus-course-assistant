设计系统 · 三层 token 与组件活样式手册

方向 B（纸感墨绿 · 专注对话）。本页的组件样式块 #ds-components 只消费 L3 component token：里面出现的每一个颜色、间距、字号、圆角、边宽、阴影、时长都写成 --<组件>-<部位>-<属性>，没有任何裸 hex 或裸长度——这是 L3 层是否完备的证明，并由 verify-system.py 机械校验。

页面自身的排版（#ds-chrome）不属于设计系统，与原型里的 .bph／.proto-banner 同性质：它允许直接用 L2 语义色与 L1 尺度原语，因为它不是产品 UI，也不该为它发明组件 token。

分层与纯度规则

  1. L1 的值必须是字面量（hex / rgba / px / em / ch / % / 无单位数 / 关键字 / 字体栈）。允许 L1 内部组合（如阴影引用 alpha 原语），但不得引用 L2/L3。
  2. L2 的值只能是 var(--p-*) 组合，不得出现字面量。
  3. L3 的值只能是 var(--...) 组合。颜色**必须经 L2**（禁止直接从 L1 取色）；间距/字号/行高/字重/边宽/圆角/尺寸/时长/缓动/z-index 等**尺度类**原语允许直取 L1（尺度只是数字，不承载语义）；禁止 L3 之间互相引用。禁止裸色值与带单位裸长度。允许无单位数值（含 0）、关键字（transparent/auto/none/tabular-nums/inherit）以及由 var() 拼接的复合值。
  4. 媒体查询的 max-width 档只允许写 (min-width 档 − 1)，如 sm 档的向下写法是 max-width:767px。
  5. 组件 CSS 规则只允许消费 L3。跨层引用（组件直接用 L2/L1）视为违规。
  6. 媒体查询断点无法用 CSS 变量表达，必须写字面量；取值只允许来自本文件 breakpoint 表。
  7. 新增 L1 值必须同时新增对应 L2/L3 引用面，否则视为未使用 token（校验脚本会报）。
